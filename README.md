## 쓰는 법

1. `AI연습` 폴더를 통째로 바탕화면에 복사합니다.
2. 1권 10·12장: Claude 앱 프로젝트의 **폴더** 칸, 또는 Code 탭 입력창 위 폴더 칩에서 이 폴더를 고릅니다.
3. 1권 17장 MCP 실습은 `AI연습` 폴더에서 다음 한 줄을 실행합니다(Node.js 필요).

   ```
   claude mcp add notes -s local -- npx -y @modelcontextprotocol/server-filesystem ./회의록
   ```

`.claude` 폴더는 숨김 폴더입니다. Mac Finder에서는 `⌘⇧.`으로 보입니다.
