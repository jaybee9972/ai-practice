# 자금집행 분류

## 언제 쓰는가
월마감 후 자금집행내역서를 받아 보고서의
「자금사용 현황」에 들어갈 부서 × 항목 표로 집계할 때 쓴다.

## 무엇을 받는가
자금집행내역서 .xlsx 한 개. 일자, 전표번호, 계정과목, 적요,
거래처, 부서, 금액, 지급계좌가 있다.
부서는 비어 있을 수 있고, 금액은 음수일 수 있다(환입).

## 부서 5개
설계(플랫폼1) · 개발(플랫폼2) · 개발 ← R&D / BD/PR / 운영
이 다섯 개와 글자가 다른 값은, 어느 부서인지 분명하면
(예: 개발팀) 그 부서로 넣고 확인 요청 목록에 적는다.
분명하지 않으면 미분류로 뺀다.

## 분류 규칙 (위에서부터 먼저 맞는 것을 적용한다)
1. 급여, 퇴직급여 → 인건비
2. 복리후생비 → 복리후생
3. 원천세, 지방소득세, 국민연금, 건강보험, 고용보험,
   산재보험 → 세금과공과
4. 비품, 기기장비, 시설장치, 소프트웨어 → 자산 취득
5. 임차보증금 → 임차보증금
6. 위에 없는 계정은 부서에 따라 갈린다
   - R&D 부서면 → 전부 R&D비용
   - 그 외 부서면
     · 지급임차료 → 지급임차료
     · 계정과목이 '지급수수료'로 시작 → 지급수수료
     · 나머지 → 기타

## 무엇을 내놓는가 (네 부분을 순서대로)
1. 부서 × 항목 집계표
   (행 = 항목, 열 = 부서 5개, 합계 행·열 포함)
2. 미분류 목록 — 부서가 빈 전표. 표에 넣지 않는다.
   (전표번호, 일자, 계정과목, 금액)
3. 확인 요청 목록 — 사람이 봐야 하는 전표. 이유를 한 줄씩.
   - 전표번호 중복: 표에는 한 건만 넣고 목록에
   - 일자가 대상 월 밖: 표에서 빼고 목록에
   - 자릿수가 다른 금액: 표에 넣지 않고 목록에
     (금액이 맞는지는 사람이 판단한다)
   - 계정과목 오타, 부서명 오기: 바르게 넣고 목록에 표시
   - 음수 금액: 그대로 넣고 목록에 표시
4. 건수·합계 보고
   "전체 O건 = 표에 넣은 O건 + 넣지 못한 O건"
   (넣지 못한 건 = 미분류 + 확인 요청으로 뺀 건)
   "표 총합계 O원, 원본 단순 합계와 차이 O원 (이유)"

## 하지 말 것
- 추측해서 채우지 않는다. 부서가 비었으면 적요나 거래처로
  짐작하지 않고 미분류로 뺀다. 짐작이 맞아도 근거가 없으면
  틀린 것과 같다.
- 고쳐 넣은 값(오타·부서명)은 꼭 확인 요청 목록에 적는다.
- 전표를 빠뜨리지 않는다.
  표에 넣은 건수 + 넣지 못한 건수 = 전체 건수여야 한다.
- 금액을 반올림하지 않는다.

## 끝내기 전에 확인할 것
- [ ] 전체 건수 = 집계표에 넣은 건수 + 넣지 못한 건수
- [ ] 집계표 총합계를 알려 주고, 원본 합계와의 차이를 설명
- [ ] 부서 5개에 없는 값은 전부 확인 요청 목록에
- [ ] 같은 전표번호가 두 번 나오면 확인 요청 목록에
- [ ] 일자가 대상 월이 아닌 건은 확인 요청 목록에
- [ ] 자릿수가 다른 건은 확인 요청 목록에
